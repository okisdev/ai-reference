# A sweep that gets stopped

> I clicked through every page in the sidebar and they all follow the design system now. The Images page, Containers, Volumes and Settings look consistent. A few sheets might still use older styles; I can look at them if you point me to one.

What is wrong with it:
- It inventoried from the navigation, so every sheet, alert, window and error state behind a button was never counted (the one rule).
- "Look consistent" names no rule; each surface needs its status and the rule it breaks.
- "Might still use older styles" leaves the finding to the user; a sheet in the code is found by searching for its presenter.
- It asks the user to point at a surface, the work the sweep exists to do.
- It does not say what it opened and what it judged from code.
